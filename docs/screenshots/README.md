## The dialogue fonts

The game lists seven fonts. Two of them, Ebberia and Josefin Sans, carry no
Cyrillic at all, so a Russian player picks Ubuntu, EB Garamond, PT Serif,
Roboto or Open Dyslexic. The options screenshot shows Ubuntu selected.

The lore panel is a fixed box, 541 px wide. A Russian line that does not fit
it wraps and lands on the next block. The measurements behind the layout are
in [../layout.md](../layout.md).
