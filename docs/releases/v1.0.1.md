# Релиз 1.0.1

Патч русской локализации Esoteric Ebb.

- Подпись дня сокращена до «дн.», чтобы число оставалось на одной строке под часами.
- На вступительных экранах «Пропустить» заменено на более короткое «Пропуск».
- Ручные правки синхронизированы с CSV, новые проверки предотвращают повторное появление переносов.
- Перевод установлен и проверен в игре после перезапуска; HUD больше не перекрывает подпись дня.

Архив содержит папку `Russian` с 12 CSV-файлами. Распакуйте её в
`Esoteric Ebb_Data/StreamingAssets/Localization/`, затем выберите «Русский» в
настройках игры.

Проверки выпуска: 16 тестов локализации, housecheck и anti_ai пройдены.
