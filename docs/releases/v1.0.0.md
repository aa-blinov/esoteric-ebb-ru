# Релиз 1.0.0

Первый выпуск полной русской локализации Esoteric Ebb.

- Архив содержит папку `Russian` с 12 CSV-файлами локализации.
- Перевод вычитан по игровым строкам; термины и имена согласованы с глоссарием и лором.
- Проверены разметка, повторяющиеся строки и размещение текста в интерфейсе.
- Чтобы установить перевод, распакуйте папку `Russian` в `Esoteric Ebb_Data/StreamingAssets/Localization/`, затем выберите «Русский» в настройках игры. Для повторного чтения файлов нажмите Ctrl+R.

Проверки выпуска: 14 тестов локализации, housecheck и anti_ai пройдены.
