# Иллюстрации и проверка пути

Комплект обновлён 31 октября 2026 года. Использован встроенный imagegen,
без обращения к CLI. Референсом послужил предоставленный пользователем
рисунок Esoteric Ebb: герои в лесу с грибами и бирюзовым освещением.
Новые рисунки являются иллюстрациями руководства, а не официальными
материалами разработчика или снимками интерфейса.

## Проверка установленной игры

Проверен каталог работающей установки на диске M, а не другая копия Steam.
От папки игры путь имеет следующий вид:

```text
Esoteric Ebb_Data/StreamingAssets/Localization/
```

В проверенной сборке он содержит ChineseCommunity, Official, Russian,
Template и Tools. На схеме показан только фрагмент: Official и Russian
являются соседними папками. Состав остальных папок может меняться между
версиями игры.

В установленной папке Russian найдены ровно двенадцать файлов:

```text
Dialogs.csv
EntityInfo.csv
Feats.csv
Glossary.csv
ItemTexts.csv
MiscTexts.csv
NPCInfo.csv
Popups.csv
QuestPoints.csv
SheetInfo.csv
SpellTexts.csv
UIElements.csv
```

В итоговой схеме дерево заканчивается выделенной папкой Russian. Файлы
под ней не показаны, чтобы сосредоточить внимание на месте установки.

## Промпты комплекта

Общее художественное задание: использовать предоставленный рисунок как
референс стиля, а не как цель редактирования. Тонкая неровная чёрная линия,
плоские фиолетовые и коричневые тени, бирюзовое освещение, грибы и небольшие
оранжевые цветы-огоньки. Светлые читаемые буквы на тёмной неровной плашке.
Декор и персонажи не закрывают текст. Без современной рамки окна, логотипа
Steam, скруглённых карточек и стрелок. Для второго и третьего шага дополнительно
передан готовый первый шаг как референс композиции серии.

### Обложка

В качестве главной обложки используется аватар, предоставленный пользователем:
портрет в фиолетовом плаще на бирюзовом фоне с вывеской Esoteric Ebb.
Он заменяет первоначальный сгенерированный рисунок жреца. Изображение
скопировано без перерисовки; для Steam отдельно экспортирована миниатюра.
Полный файл: assets/cover.png; миниатюра: assets/cover-195.png.

### Шаг 1: ветка локализации

Горизонтальная инструкция с большой тёмной рисованной областью для текста.
Небольшой жрец у правого края указывает на инструкцию, не перекрывая буквы.
Четыре строки идут сверху вниз; Localization Branch выделена оранжевым.
Текст, переданный для размещения:

```text
01. ВКЛЮЧИТЕ ЛОКАЛИЗАЦИЮ
Библиотека Steam
Esoteric Ebb: Свойства
Бета-версии
Localization Branch
Дождитесь обновления игры
Схема установки
```

Файл: assets/01-beta.png.

### Шаг 2: архив

Горизонтальная инструкция в композиции первого шага. Небольшой зелёный
гоблин в пурпурной одежде у правого края держит свиток; в левом нижнем углу
свиток и рисунок папки. Инструкция о скачивании последней версии выделена
оранжевым. Номер версии и конкретное имя ZIP не указаны.
Текст, переданный для размещения:

```text
02. СКАЧАЙТЕ ПЕРЕВОД
GitHub: последний релиз
Откройте Assets
Скачайте архив последней версии
Внутри: папка Russian
Source code для установки не нужен
Схема установки
```

Файл: assets/02-download.png.

### Шаг 3: папки

Горизонтальная инструкция в композиции первого шага. Дерево папок занимает
основную площадь, Russian выделена оранжевым. Соединители представляют собой
линии с прямыми углами без наконечников стрелок. Official и Russian на одном
уровне; под Russian нет файлов и дополнительных веток. Жрец справа не закрывает
буквы. Текст и вложенность, переданные для размещения:

```text
03. УСТАНОВИТЕ ПЕРЕВОД
Папка игры
Esoteric Ebb_Data
  StreamingAssets
    Localization
      Official
      Russian
Перенесите Russian из ZIP в Localization.
Фрагмент содержимого папки
```

Файл: assets/03-folders.png. Вложенность на готовом рисунке сверена с
проверенным каталогом. Второй рисунок предлагает скачать последнюю версию
без конкретного номера, поэтому при смене версии обновлять его не нужно.
