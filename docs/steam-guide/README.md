# Материалы для руководства Steam

Готовый текст и иллюстрации для сообщества Esoteric Ebb. Пакет подготовлен для версии перевода 1.0.2. Статья в Steam пока не опубликована.

## Поля руководства

- Название: **Esoteric Ebb на русском — русификатор и установка за 3 шага**.
- Краткое описание: **Хотите играть в Esoteric Ebb на русском? Скачайте неофициальный русификатор и установите его за три шага. Внутри: ссылка на последнюю версию, картинки установки и помощь с настройкой шрифта.**
- Язык: **Русский**.
- Категория: выберите доступную в редакторе категорию для настройки игры или модификаций.
- Обложка: [assets/cover-195.png](assets/cover-195.png).

Три изображения установки являются схемами, а не снимками клиента Steam.
Игровые скриншоты скопированы без изменений из `docs/screenshots/`; это ранее
сделанные снимки перевода, а не доказательство проверки текущего релиза.
На снимке настроек важны язык, шрифт и размер; подписи лимитов относятся к
предыдущему состоянию перевода. Игровая графика принадлежит её правообладателям.

## Как опубликовать

1. Откройте [руководства Esoteric Ebb](https://steamcommunity.com/app/2057760/guides/) под своим аккаунтом Steam и выберите создание руководства. Steam разрешает создавать руководства для игр из вашей библиотеки.
2. Заполните название, описание, язык и категорию из блока выше. Загрузите квадратную обложку. Здесь выбран размер 195 × 195 пикселей по рекомендации руководства сообщества; это не заявленный нами жёсткий лимит Steam. Полный рисунок сохранён отдельно в assets/cover.png.
3. Создайте разделы в порядке таблицы. [article.md](article.md) удобно читать в GitHub, а [steam-bbcode.txt](steam-bbcode.txt) содержит текст с разметкой Steam для переноса в редактор. Вставляйте соответствующий раздел, а не весь текст в каждую секцию.
4. Загрузите изображения из `assets/` через редактор руководства. Вставьте их в соответствующие разделы встроенной командой вставки изображения. Steam создаёт собственные ссылки после загрузки; локальные пути и GitHub Markdown в опубликованном тексте работать как вставленные изображения не будут.
5. Проверьте предпросмотр: все семь разделов, читаемые картинки, работающие ссылки на релиз и GitHub Issues, отсутствие технических пометок. Убедитесь, что выбран именно русский язык руководства.
6. Опубликуйте руководство и проверьте его страницу. Добавьте получившуюся ссылку в основной README проекта.

Обложка взята из предоставленного пользователем аватара. Схемы
созданы встроенным инструментом imagegen по предоставленному
пользователем референсу Esoteric Ebb. Бирюзовый свет, фиолетовые тени,
неровная тушевая линия и рисованные плашки объединяют комплект.
Это схемы установки, а не снимки интерфейса Steam. Полноразмерные файлы
оставлены для просмотра крупнее; редактор Steam может уменьшить их при вставке.
Команда `python docs/steam-guide/build_assets.py` только экспортирует миниатюру
обложки и копирует игровые скриншоты, она не перерисовывает схемы.
[Промпты и проверка пути](image-prompts.md).

## Что проверено в интернете

- [Steam Support: Steam Guides](https://help.steampowered.com/en/faqs/view/7E51-0A01-FAF2-BDAE): создание руководств для игр в библиотеке. Страница поддержки в веб-инструменте загрузилась неполно; это положение подтверждено её поисковой выдержкой.
- [Разметка Steam](https://steamcommunity.com/comment/Guide/formattinghelp): заголовки, выделение, ссылки и списки. На ней основан файл steam-bbcode.txt.
- [Tips for Creating Steam Guides](https://steamcommunity.com/sharedfiles/filedetails/?id=837385938): рекомендации сообщества по обложке 195 × 195 и ширине иллюстраций 638 пикселей, а также загрузке изображений в редакторе. Это пользовательское руководство, а не спецификация Valve; обязательные ограничения проверяются по текущей форме загрузки.

В статье и схеме скачивания используется последняя версия без конкретного
номера архива. Постоянная ссылка `/releases/latest` остаётся прежней.
После публикации материала в Steam изменения в GitHub
не обновляют текст руководства автоматически.
