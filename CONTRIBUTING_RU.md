# Как внести вклад

Сообщество поддерживает русскую локализацию Esoteric Ebb в этом репозитории.
Мы рады правкам перевода, уточнениям лора, исправлениям интерфейса, тестам и
документации.

## Перед правкой

- Сверься с [руководством по стилю](docs/style-guide.md) и
  [глоссарием](docs/glossary.md).
- Перед правкой интерфейса изучи [замеры](docs/layout.md).
- Найди английскую исходную строку и её повторы. Одинаковый исходник должен
  иметь одинаковый русский перевод.
- Сначала открой issue, если планируешь крупную переработку, массовую смену
  термина, изменение пайплайна или процесса релизов.

## Правки перевода

1. Исправь строку в `translation/Russian/`.
2. Продублируй её в `src/voice/manual_fixes.json`, иначе следующий прогон
   пайплайна может вернуть прежний вариант.
3. Сохрани плейсхолдеры и теги разметки как в английском исходнике. Не меняй
   столбцы CSV. Нулевую ширину используй только для строки, которая должна
   остаться пустой.
4. Добавь или обнови тест, если исправляешь повторяющийся дефект. Замер ширины
   занеси в `docs/layout.md`, а заметную для игрока правку внеси в `CHANGELOG.md`.
5. Если меняется интерфейс, установи локализацию в свою копию игры, перезапусти
   игру или нажми Ctrl+R. Приложи снимок экрана с разрешением и настройками
   шрифта.

## Проверки

Из корня репозитория выполни:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/scan_ai_patterns.py --verbose
```

GitHub Actions запускает проверки `Check and test` и `House style` для каждого
pull request. Проверка стиля хранится в соседнем репозитории `golden-repo`.
Если он находится рядом с локализацией, запусти:

```bash
python ../golden-repo/scripts/housecheck.py .
python ../golden-repo/scripts/anti_ai.py --dir .
```

Для замеров шрифта укажи `EB_GAME_DIR` и запусти
`python src/ebru/measure_width.py`. Чтобы установить перевод для проверки,
закрой игру, задай `EB_GAME_DIR` и выполни `python scripts/install.py`.

## Pull request

- Работай в отдельной ветке. Предложения не отправляй напрямую в `main`.
- Опиши результат для игрока, перечисли изменённые ключи и добавь контекст
  английского оригинала или лора.
- Для видимых правок интерфейса приложи снимки и точные результаты проверок.
- Не объединяй несвязанные исправления в один запрос.
- Перед слиянием дождись успешных проверок и ответь на замечания ревью.

## Изменения кода

- CI использует Python 3.12 и `unittest`. Следуй стилю соседних модулей и тестов.
- Делай небольшие и предсказуемые изменения. Не меняй сгенерированные CSV,
  не обновив ручные правки или сам пайплайн.
- Сохраняй минимальные разрешения workflow. Объясняй в pull request, зачем
  добавлены зависимость или внешнее действие.
- Автоматического форматтера и линтера в проекте нет. Соблюдай стиль соседнего
  кода и запускай тесты до создания pull request.
