# Esoterica

[English README](README.md)

Русский перевод **Esoteric Ebb**: диалоги, история, предметы, заклинания и меню.

## Установка за три шага

**Сначала удалите любые другие русификаторы Esoteric Ebb:** чужие папки с переводом в `Esoteric Ebb_Data/StreamingAssets/Localization/` (оставьте только `Official` и папки, которые положила сама игра) и моды, которые подменяют тексты или шрифты. Две русификации сразу могут конфликтовать, а в списке языков окажется не тот перевод. Если остались сомнения, в Steam: **Свойства → Установленные файлы → Проверить целостность файлов**.

1. В Steam: **Библиотека → правая кнопка по Esoteric Ebb → Свойства → Бета-версии**. Выберите **Localization Branch** и дождитесь обновления.
2. Скачайте **esoteric-ebb-ru-v1.0.4.zip** из [последнего релиза](https://github.com/aa-blinov/esoteric-ebb-ru/releases/latest). Нужен архив перевода, а не `Source code`.
3. Откройте папку игры: **правая кнопка по игре → Управление → Просмотреть локальные файлы**. Перетащите папку `Russian` из скачанного ZIP в `Esoteric Ebb_Data/StreamingAssets/Localization/`, рядом с `Official`.

Запустите игру и выберите **Настройки → Язык → Русский**. Если игра была открыта во время установки, полностью перезапустите её.

Выберите шрифт **Ubuntu** и размер диалогов **22**. Ebberia и Josefin Sans не поддерживают кириллицу.
