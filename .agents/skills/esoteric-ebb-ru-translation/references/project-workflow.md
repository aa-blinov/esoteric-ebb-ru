# Рабочий процесс локализации Esoteric Ebb RU

Этот файл дополняет `.agents/skills/esoteric-ebb-ru-translation/SKILL.md` командами и ограничениями конкретного репозитория. Если команда изменилась, сверь её с `AGENTS.md` и самим файлом, прежде чем запускать.

## Источники и файлы

- `translation/Russian/` — 12 CSV, которые игра загружает как язык RU.
- `src/voice/glossary.json`, `docs/glossary.md` — закреплённые термины и имена.
- `src/voice/bible.md`, `docs/style-guide.md` — голос редактора и литературные правила.
- `src/voice/manual_fixes.json` — исправления, которые должны сохраниться при сборке.
- `docs/layout.md` — реальные размеры панелей и уже исправленные переполнения.
- `tests/` — проверки CSV, разметки, повторов, ширины и настроек.

Сначала найди ключ в английском источнике и проверь его повторы:

```powershell
rg -n "KEY_NAME" translation src/voice docs
```

Не считай строку переводимой, пока не подтвердил, что она существует в RU CSV. Часть панелей игра строит из собственных строк, а пустая ячейка RU показывает английский оригинал.

## Ручная правка

1. Исправь RU ячейку в нужном CSV и внеси тот же вариант в `src/voice/manual_fixes.json`.
2. Примени сохранённые правки:

```powershell
python -m src.ebru.apply_manual
```

3. Проверь тесты и текстовые правила:

```powershell
python -m unittest discover -s tests -v
python scripts/scan_ai_patterns.py --verbose
```

В рабочем окружении автора, где соседняя папка `golden-repo/` доступна из корня репозитория, также запускаются:

```powershell
python ..\golden-repo\scripts\housecheck.py .
python ..\golden-repo\scripts\anti_ai.py --dir .
```

В обычном клоне эти два скрипта могут отсутствовать; соответствующая проверка выполняется workflow `House style` на GitHub.

Для замера фактических метрик шрифта игры укажи `EB_GAME_DIR` и запусти:

```powershell
python src/ebru/measure_width.py
```

Полный пайплайн доступен командой `python src/ebru/build.py --stage all`. Он может вызывать модель и читает настройки endpoint из окружения; не запускай его как замену одной ручной правке. Кэш находится в `work/cache/`.

## Установка и экранная проверка

Перевод предназначен для бета-ветки **Localization Branch**. Разработчик добавил в неё новый текстовый движок и поддержку пользовательских языков; обычная ветка может не загружать пользовательский каталог языка. Перед экранной проверкой переключи игру в Steam: **Свойства → Бета-версии → Localization Branch**, дождись обновления и проверь версию игры.

Для локальной установки закрой игру, задай `EB_GAME_DIR` и запусти:

```powershell
$env:EB_GAME_DIR = 'D:\SteamLibrary\steamapps\common\Esoteric Ebb'
python scripts/install.py
```

Проверь полный путь до запуска: установщик удаляет и создаёт заново папку `Esoteric Ebb_Data/StreamingAssets/Localization/Russian`. Он также переводит `FontIndex` на Ubuntu (6), если в настройках выбран один из двух шрифтов без кириллицы: Ebberia (0) или Josefin Sans (2).

Игра читает CSV при запуске; во время игры можно перечитать их сочетанием Ctrl+R. Новый каталог языка требует перезапуска. `LanguageCode` находится в `SETTINGS.es3`; игра перезаписывает настройки при выходе, поэтому меняй их только при закрытой игре и проверяй после сессии.

Диалоговый размер 22 используется для русской версии; исходное значение игры — 24. Изменение глобального размера делает прежние замеры ширины недействительными. Не меняй его ради одной подписи без повторной проверки затронутых экранов.

В авторском рабочем окружении снимки и ввод доступны через `..\tools\capture\capgame.ps1`, `clickgame.ps1` и `sendcombo.ps1`; игровые настройки находятся в `..\tools\settings\`. Утилита захвата может выбрать не то окно, если запущено несколько экземпляров игры. Сверь картинку, сохранение и PID окна перед выводом о результате. Не закрывай активные экземпляры без проверки несохранённого прогресса.

Для UI-исправления зафиксируй разрешение, используемый экран и фактический результат. Запиши замер в `docs/layout.md`. Не считай проблему решённой по одному исправленному CSV, пока не проверил перезагруженный текст в нужном экране или ясно не отметил, что визуальная проверка недоступна.
